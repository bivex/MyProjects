# My Projects

The meta-repository. A master catalog for tracking all projects using Obsidian as a knowledge base.

## Structure

This is an [Obsidian](https://obsidian.md/) vault for project tracking and management.

```
├── templates/          # Note templates
├── Проекты/            # Project notes
├── .obsidian/          # Obsidian configuration
├── Dataview-Snippets.md # Dataview query examples
└── YYYY-MM-DD.md       # Daily notes
```

## Usage

Open this folder as an Obsidian vault to browse and manage project notes. Daily notes are organized by date, and projects are tracked in the `Проекты/` directory.

## Templates

- Еженедельный план - Weekly planning template
- Ежедневная заметка с задачами - Daily note with tasks
- Новая задача проекта - New project task template
